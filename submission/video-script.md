# Demo narration — Stage Manager

**Runtime target:** ~2:00 (hard stop 3:00).  
**Voice:** Microsoft neural TTS in the agent reel (`en-US-AndrewMultilingualNeural`). For a human recut, paste `submission/demo-reel/vo/narration.md` into ElevenLabs / ChatGPT Voice / a mic — do not re-staccato this into slogan slides.

Tone: one person explaining a real ops problem, then showing the product. Full sentences. Problem first.

---

## Spoken track (do not chop into title cards)

### 1 — Problem

Every company pages an engineer when a server goes down. Almost nobody pages the human who owns the renewal when the account goes quiet.

Customer Success owns the revenue relationship. Slack owns the noise. When a named account is looping in support — two bot handoffs, ticket still open, enterprise on the line — the alert is just another message in a river of messages. Until churn is already expensive.

That is the problem.

### 2 — Insight

Phone still cuts through. Not as a spam dialer to the customer. As a sixty-second interrupt for the CS owner. Rare. Short. Structured. One, two, or three. Then hang up.

This is Stage Manager.

### 3 — Over the real CLI

Judges run the whole loop with no API key. Dress rehearsal is the default: same call sheet, same line readings, same prompt book — no ring. Four cues, one engine: stuck support, SLA risk, agent needs a human, health or onboarding stall.

### 4 — Live call (two voices)

Host, over the ring: When we took it live, CALL-E rang the CS owner only. Never the customer.

Stage Manager: Hi. Stage Manager. You are up for Acme. Stage code — please repeat: four eight two one.

Owner: Four eight two one.

Stage Manager: Line reading. Say one, two, or three. One: take over in chat now.

Owner: One.

Stage Manager: Logging takeover in the prompt book. Clear. Break a leg — or just open the ticket.

### 5 — Close

That decision is state. Not a Slack shrug. An action intent for the next system. Ack is not a decision. This is.

When the account is on fire, we cue the firefighter — not the building. Stage Manager. No customers were called in the making of this demo.
